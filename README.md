# 🛡️ Urban Guardian – Smart Women's Safety Platform

**Navigate Safely. Stay Aware. Travel Confidently.**

Urban Guardian is a web-based women's safety platform designed to make everyday travel safer through location-based navigation and safety awareness. It aims to help users identify safer routes, understand potentially high-risk areas, and make more informed travel decisions.

The platform focuses on combining interactive maps, location-based services, and safety insights to create a smarter and more accessible travel experience.

## ✨ Key Features

- **🗺️ Smart Route Identification:** Helps users identify safer routes to their destinations.
- **🔥 Safety Heatmap:** Visual representation of potentially high-risk areas to improve situational awareness.
- **📍 Location-Based Navigation:** Uses geographical information to support route planning.
- **🛡️ Women's Safety Focus:** Designed around the safety concerns of women during daily commutes and travel.
- **💻 Interactive User Interface:** Simple and accessible interface for exploring safety-related information.
- **🚦 Safety Awareness:** Encourages users to consider area-level safety information before choosing a route.

## 🚀 Getting Started

Follow these steps to run the project locally.

### 1. Clone the Repository

```bash
git clone https://github.com/Saksham1781/Urbanguardian.git
```

### 2. Navigate to the Project Directory

```bash
cd Urbanguardian
```

### 3. Run the Application

Open `index.html` in your browser.

Alternatively, use the Live Server extension in Visual Studio Code for a better development experience.
